# הלוז שלי · אינדינגב 2026

אפליקציה אישית לטלפון לניהול לוז ההופעות. **קובץ אחד, בלי אינטרנט, בלי שרת.**

הקובץ להעתקה לטלפון: `dist/indienegev.html` (כ-950KB). המפה, הפונט, האיורים וספריות ה-QR כולם בתוכו.

## התקנה על הטלפון

**אנדרואיד:**
1. מעתיקים את `indienegev.html` לתיקיית **Download** בטלפון: בכבל USB, או מורידים מ-Google Drive או מוואטסאפ ששלחתם לעצמכם.
2. פותחים את Chrome וכותבים בשורת הכתובת: `file:///sdcard/Download/indienegev.html`. אם Chrome מבקש הרשאה לקבצים, מאשרים.
   - **חשוב:** לא לפתוח את הקובץ ישירות מוואטסאפ או מאפליקציית "קבצים". בדרך הזו הכתובת יכולה להשתנות בכל פתיחה, והבחירות "נעלמות".
3. מוסיפים סימנייה (⭐ בתפריט ⋮), ואם האפשרות מופיעה גם "הוספה למסך הבית".
4. **בדיקת שמירה:** מסמנים הופעה, סוגרים את Chrome לגמרי (מחלון האפליקציות האחרונות), ופותחים שוב מהסימנייה. ההופעה צריכה להופיע ב"הלוז שלי".
   - אם היא לא מופיעה, או שמופיעה הודעה אדומה על שמירה, עושים את אותו דבר ב-**Firefox** (אותה כתובת).
5. שומרים קוד גיבוי (לוגו ← "העתקת קוד גיבוי") בהודעה לעצמכם.

**iPhone:** ספארי לא שומר מידע כשפותחים קובץ HTML מקומי. האפשרות המעשית היא לארח את הקובץ פעם אחת באחסון סטטי (GitHub Pages / Netlify Drop) ולפתוח אותו משם. ראו סעיף 8 באפיון.

## פיתוח

```
python app/build.py      # בונה את dist/indienegev.html
```

| קובץ | תוכן |
|---|---|
| `src/data.js` | כל הלוז (מה-PDF + דף אדמה). **לא לשנות סדר פריטים**, כי האינדקס משמש בקודי שיתוף. מוסיפים רק בסוף |
| `src/core.js` | זמנים, שמירה, קידוד שיתוף, חיפוש, התנגשויות |
| `src/ui.js` | אייקונים, גיליון תחתון, פאנלים, טוסט, כפתור "חזור" |
| `src/grid.js` · `mine.js` · `sheet.js` · `search.js` · `map.js` · `now.js` · `share.js` · `friends.js` | המסכים |
| `src/main.js` | טאבים, כותרת, הגדרות, אתחול |
| `vendor/` | פונט Rubik (OFL), qrcode-generator (MIT), jsQR (Apache-2.0) |
| `assets/` | מטמון של תמונות מעובדות. מוחקים כדי לייצר מחדש |

מיקומי הבמות על המפה מוגדרים ב-`STAGES` (`mapX`/`mapY` באחוזים).
